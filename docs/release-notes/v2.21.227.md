# Kimix v2.21.227

## 修复与优化

- **修复点击「设置」或折叠侧栏时整个窗口崩溃（白屏/报错页）的问题**：上个版本引入的界面结构调整导致该场景必现崩溃，现已修复，设置弹窗与侧栏折叠恢复正常。
- **Mica 窗口材质视觉修正**（Windows 11）：修复开启 Mica 后顶部菜单栏与侧栏颜色深浅不一、四角露出底色的问题；修复对话区域误透出外壳颜色的问题——对话区恢复为干净的不透明背景，侧栏/顶栏/底栏保持 Mica 半透明透出。
- 应用内报错页现在会展示更完整的错误堆栈，并自动写入诊断日志；遇到偶发崩溃时，反馈问题附带的诊断信息更充分，定位更快。

## 已知边界

- Mica 模式下窗口四角为 Windows 系统圆角（固定约 8px），不跟随界面主题的圆角大小；这是 Windows 平台对 Mica 不透明窗口的固定行为。窗口最大化时四角为直角，与系统原生应用一致。
