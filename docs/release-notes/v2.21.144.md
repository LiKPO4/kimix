# Kimix v2.21.144

## 新功能

- 接入官方 Tower 协作编排（实验功能，默认关闭）。在 设置 → 实验功能 开启并重启后，可通过输入区加号菜单或工具栏开启 Tower 模式，由多个子 Agent 并行协作完成任务；右侧检查器实时只读展示任务、Agent 与活动进展，输入区「后台 Agent」胶囊支持最近/进行中/已完成/全部筛选。Tower 与 Plan、Swarm 互斥，退出仅关闭模式并保留工作区。
- 新增「子 Agent 上下文 fork」实验开关（默认关闭）。开启后子 Agent 可携带调用方的完整对话上下文；请注意多子 Agent 并行时会按成员数放大上下文与成本。
- 新增「消息自动折叠」开关（设置 → 对话与权限 → 过程展示方式），回合结束时自动折叠工作过程、仅展示总结，**默认开启**，可随时关闭。
- 跟进官方 Kimi Code 0.39 运行时：状态事件恢复实时 Context 用量显示；Server 会话的「转后台」改用官方任务分离接口，不再提示不支持。

## 修复与优化

- 修复历史会话图片显示「未读取到绝对路径」占位卡的问题：接入官方 blobref 内容寻址，并让持久化的旧坏数据在启动对账时自动修复，不再反复触发。
- 修复弹窗压暗背景在透明窗口四个圆角外露出黑色方块的问题；最大化/全屏时保持矩形。
- 修复聚焦输入框会误收起已打开的后台任务卡片的问题。
- 设置 → 模型与供应商：「删除供应商」按钮移至「凭据就绪」右侧；修复自定义界面风格下左侧供应商列表与外层卡片圆角错位形成的缝隙；「默认」按钮悬停时现在会显示明确的蓝色预览高亮，可点击性一目了然。
- 设置页「返回对话」按钮移至侧栏底部，与对话页「设置」按钮在同一位置，点同一位置即可在设置与对话间来回切换。
- 顶部菜单栏与各页面工具栏高度统一收缩，为对话区释放纵向空间；模型页卡片圆角体系统一。
- 修复自定义界面风格下 Tab 选中态不显示、Tower 筛选框圆角异常的问题；工具栏「打开方式」组合按钮与普通图标按钮圆角统一。
- Tower 卡片状态以官方终态为准，不再被滞后的任务列表状态覆盖。

## 已知边界

- Tower 为实验功能且默认关闭；开启后由官方运行时操作 Git 工作区（创建独立工作副本与分支）。退出 Tower 保留工作区内容；清理（Teardown）需工作区无未提交改动，不提供强制清理。
- 「消息自动折叠」默认开启；如希望始终展开工作过程，可在 设置 → 对话与权限 中关闭。
