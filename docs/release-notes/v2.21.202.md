# Kimix v2.21.202

## 新功能

- 设置 → 消息信息新增「气泡内容」开关：模型、输入 Tokens、输出 Tokens、上下文用量、输出速率五项可分别开关，默认全开；关闭后回合结束气泡不再显示对应信息，全部关闭时不显示空胶囊。
- 回合结束气泡新增输出速率（tokens/s）显示。

## 修复与优化

- 修复回合结束气泡输出速率异常：此前可能显示明显偏低（工具执行时间被计入生成耗时）或干脆不显示（轮末汇总帧查不到速率）；现在速率与本轮累计输出 Tokens 同口径，仅统计模型生成时间。
- 大幅改善大会话流式输出期间的滚动卡顿（长历史会话、持续输出时尤为明显）。
- 修复右侧 Plan 卡片在 Agent 每执行一步时闪烁的问题：内容刷新不再整块退回「正在读取 Plan 内容...」占位；计划文件有新内容时仍会就地更新。
- 修复右侧 Kimi Code 状态卡片在每个轮次起止时图标反复切换的问题，并减少不必要的重复检测（详细诊断仍可手动刷新）。
- 状态胶囊里的「Context」改为中文「上下文」；「消息处理中」提示与状态卡片风格统一（自定义界面风格下同样生效）。

## 已知边界

- 输出速率为基于事件时间戳的近似值（未使用官方流式计时），与官方 CLI 展示可能存在小幅差异；等待你确认或批准的时间不计入生成窗口。
