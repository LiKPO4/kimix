- 修复单 Agent 对话发送消息时误将多 Agent 房间指令拼接到官方 API 端的问题。
- 修复旧会话切换模型后，新发送消息头部依然误用旧模型名称的问题。
- 修复 Agent 协同房间首条消息缺少当轮模型标头的问题。
- 修复 Agent 房间撤回消息后，被撤回消息在界面残留的问题。
- 修复引导与新建会话场景下出现的重复刻度与双重流式渲染问题。
