# Kimix v2.20.145

本版本从上一个实际发布版本 **v2.20.75** 起算，覆盖界面风格体系、深浅色对比度、会话侧栏与任务面板、草稿可靠性、子 Agent 模型同步，以及大量对话与顶栏体验打磨。

## 界面风格

- **三套界面风格**：在设置 → 外观中可切换 **Kimix 默认**、**现代化**、**复古**。风格只改变圆角、边界、阴影与控件质感，不会替换你当前的颜色主题。
- **现代化**：更明亮的工作画布、安静侧栏、大圆角内容区与轻薄悬浮层次；工具调用卡片改为接近官方客户端的浅灰底，不再显得过重。
- **复古**：小圆角、清晰描边与克制高光；按钮悬停/选中、浮层与会话侧栏控件统一质感，并减少「框套框」双层边框。
- 修复默认工具栏被新风格误伤、选中标记串用、按钮双层描边、会话文字内框等问题。

## 颜色与可读性

- **深色模式**：重建表面层级（画布 / 面板 / 悬停），边框改为更清晰的浅色描边，次要文字对比度提升，侧栏与主区更容易区分。
- **浅色默认配色**（暖纸、灰白、淡绿、暖橙等）：加深次要文字与边框，拉开背景层级，设置卡片和列表轮廓更易辨认。
- 色彩方案与主题分区在外观页中独立展示，格式统一。

## 会话侧栏与任务

- 新增 **后台 Bash**、**子 Agent** 任务面板；无后台任务时自动隐藏，减少无效刷新闪烁。
- 项目会话列表默认只显示最近 5 个，展开/收起显示剩余数量。
- **最近变更**与对话流中的文件变更记录对齐；文件预览支持排序，并优化预览侧栏留白与层次。
- 侧栏分区卡片、Git 操作、列表行等接入统一风格角色；标题与内容间距更舒适。
- 已选中项目/会话在悬停时会有与普通行一致的描边反馈，而不会「悬停无变化」或状态错乱。

## 顶栏与窗口

- 运行、打开工作区等分体按钮：默认不再像一直选中；打开菜单时使用克制的表面悬停色，而不是整块蓝色「模式选中」底。
- 窗口最小化 / 最大化 / 还原 / 关闭图标统一为常见方框与横线样式。
- 对话左侧导航刻度条在最大化后仍固定在聊天区左缘，不再跟着中间内容柱漂移。

## 对话与草稿

- 未发送文字按会话自动保存；切换设置、插件或其他会话后可恢复，应用重启后文字草稿仍在。
- **多窗口**：同一会话在多个窗口打开时，各窗口草稿互不直接覆盖；重新打开时恢复最近更新的草稿。
- **说明**：未发送附件可在工作区与会话间往返保留；完整退出应用后附件仍不会恢复。
- 修复助手状态偶尔只显示裸「已完成」、空态建议与图标语义等问题。
- 用户消息、元信息与代码块在现代化风格下的明度层级更清晰。

## 模型与子 Agent

- 设置中的 **子 Agent / Swarm 模型** 会同步写入 Kimi Code 配置，并尽量对已连接的官方 Web 热更新，使后续新建的子代理与 Swarm 使用指定模型。
- 默认模型标识与按钮展示更清楚，长模型名不易被截断。
- Swarm、Plan、权限与思考强度等控件的悬停/选中反馈更统一。

## 设置与工作区

- 设置页统一工作区顶栏，保留返回对话与设置导航上下文。
- 插件、Hooks 等页面与主界面风格角色对齐。

## 已知边界

- 未发送**附件**在完整退出应用后仍不会自动恢复。
- 子 Agent 模型依赖本机 Kimi Code 版本能力；较旧版本可能仅写入配置、无法热读全部实验标志。
- 若你曾手动改过色彩方案且界面颜色看起来偏旧，可在外观中重新选择一次配色方案以刷新。
