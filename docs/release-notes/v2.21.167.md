# Kimix v2.21.167

## 新功能

- 内置 Kimi Code 运行时升级到官方 0.40.1，同步上游近期的多项改进：Tower 模式支持指定基础分支、会话 fork 提速、配置保存更稳定等。
- 对话输入框的 `@文件` 搜索在内置运行时会话下改用官方文件建议引擎，搜索结果更贴合项目实际；官方能力不可用时仍回退到本地搜索。

## 修复与优化

- YOLO（自动通过）模式的安全边界与官方 0.40 对齐：普通工具操作仍然自动批准，但危险命令（如关机、删除整目录）和敏感操作现在会弹出确认卡片，由你决定是否放行，不再被静默执行。Composer、设置页和 Room Agent 弹窗的说明文案已同步更新。
- Tower 模式开启时以当前分支作为基础分支，预检提示更新为官方 0.40 的真实行为：首次创建任务分支会把未提交的改动作为基础快照带入；若主工作区仍有与待合并文件重叠的改动，合并会被拒绝。
- Kimi Code 配置保存改为原子写入，避免后台进程在保存瞬间读到不完整配置，导致模型与供应商列表短暂消失。

## 已知边界

- Tower 预检通过后、点击开启前如果切换了分支，会以预检时确认的分支作为基础分支。
- 危险命令防护由官方 Kimi Code 0.40 提供；如需关闭，可在 `config.toml` 的 `[permission]` 段设置 `dangerous_command_guard = false`。
