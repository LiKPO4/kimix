# Kimix v2.20.119

本版本从上一个实际发布版本 v2.20.75 起算，集中更新界面风格体系、设置与插件工作区、侧栏任务管理、草稿可靠性和多项对话体验。

## 全新界面风格体系

- **新增三套界面风格**：可在 Kimix 默认、现代化和复古之间切换；界面风格只改变圆角、边界、阴影和交互质感，不会覆盖当前颜色主题。
- **现代化工作台**：采用更明亮的主画布、完整圆角导航、轻量表格和克制的悬浮层次，输入区、设置页、插件页与 Hooks 页面保持统一。
- **复古 Platinum 风格**：使用小圆角、薄边界和轻微浮雕反馈；项目、会话、工具按钮、弹窗和输入区统一进入同一套交互语言，同时保留清晰的悬停态与选中态区分。
- 修复默认、现代和复古之间选中标记串用、按钮双层描边、会话文字内框、工具栏分割线误删及内外圆角不一致等问题。

## 设置与扩展工作区

- 设置页使用统一工作区顶栏，并保留左侧“返回对话 / 设置”上下文；正文不再重复显示当前分类标题，更多空间用于实际配置内容。
- 设置页主题、权限、模型与色彩方案等内容统一圆角和层级；模型诊断与刷新操作保留为紧凑工具行。
- 插件页统一管理本地 Skills 与 MCP 服务，支持导入 Skill、查看来源与启用状态。

## 侧栏与任务管理

- 侧栏新增后台 Bash 与子 Agent 任务面板，后台任务空态会自动隐藏，刷新时不再闪烁。
- 项目会话默认折叠为最近 5 个，展开与收起入口显示剩余数量。
- 文件预览支持排序切换，“最近变更”与对话流中的变更记录保持一致。

## 对话与草稿可靠性

- 未发送文字会按会话或新项目对话自动保存，切换到设置、插件或其他会话后仍可恢复，应用重启后也不会丢失。
- 同一会话在多个窗口打开时，每个窗口使用独立草稿槽，不再直接覆盖另一个窗口尚未发送的文字；重新打开时恢复最近更新的草稿。
- 未发送附件可在工作区和会话之间往返保留；完整退出应用后附件仍不会恢复，重新发送前请勿依赖附件跨重启保存。
- 优化用户消息、模型用量信息和 Agent 行内代码的明度层级，消息归属更清晰。
- 修复 Assistant 状态偶尔回落为裸“已完成”、空态建议重复“继续”及建议图标语义丢失等问题。

## 模型与常用控件

- 默认模型标识与模型按钮语义更明确，长模型名可完整显示。
- Swarm、Plan、权限与思考强度等控件统一悬停和选中反馈；二元模式保持完整按钮选中面，不再误用侧栏左侧标记。
