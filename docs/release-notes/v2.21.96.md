# Kimix v2.21.96

## 修复

- 修复自定义模型识图能力丢失：官方 Kimi Code 更新后，自定义模型（接入 OpenAI 兼容供应商的模型）无法查看发送的图片和视频，只能拿到文件引用。本版起会自动为自定义模型补写所需的能力声明，已有配置会在启动时自动迁移，不再需要手动改配置文件。
- 修复部分 deepseek 系列视觉模型（如 `deepseek-v4-flash-vision-exp`）因名称误判被降级为纯文本模型、图片无法送达的问题。
- 修复思考内容错乱：流式思考与历史快照回放切换时出现的文字重复、乱序、中段重叠错乱已修复；重连或恢复会话时思考内容不再可能被整段删空。
- 修复侧栏会话标题反复横跳：本地推导标题与官方目录策略统一，短消息（如「Hi」）也可作为标题，与官方列表一致。

## 优化

- 侧栏展开/切换项目即时显示已有会话，不再强制等待目录刷新（此前切换项目可能等待约 3-4 秒加载占位）；目录刷新在后台进行，归档的新增会话随之平滑更新。
- 侧栏展开时 Web 端已归档的会话不再先显示后消失；目录刷新失败时退回显示当前已知会话，不会一直停留在加载状态。

## 已知边界

- 若自定义模型本身不支持图片输入，发送图片会自动降级为文字描述以避免请求报错；如需对某个模型关闭图片能力，可在 `config.toml` 中将其 `capabilities` 改为 `[ "tool_use" ]`（不要删除该行）。
- 展开项目后，若会话在其它客户端（如 Web 端）刚被归档，列表会在下一次目录刷新（最长约 30 秒）时更新一次。
- 思考去重仅在流式重连/快照回放产生重复重叠时生效；若相邻思考段以相同的较长短语开头或结尾，去重可能误判，后续根据实际数据调整。
