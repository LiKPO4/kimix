# Kimix v2.20.75

本版本从 v2.20.45 起算，包含设置页全新分类导航、发送-回复全链路可靠性修复、长程任务状态持久化修复、内置 Kimi SDK 升级 0.31 与多项界面打磨。

## 设置页

- **全新分类导航**：设置拆分为基础设置（常规/外观）、对话与权限、Kimi Code（账户与连接/模型与供应商）、高级（实验功能/数据管理/诊断）分区，左侧分类直达。
- **模型与供应商页**：进入页面不再默认展开「编辑模型」卡片——点击某个模型后才显示编辑表单，点「添加模型」或选择探测结果才显示添加表单；页面顶部现在标注「默认模型 xx」。

## 发送与回复可靠性

- **审批与提问卡片显示真实内容**：使用官方 Server 时，审批卡现在显示真实的工具名与命令预览，提问卡保留「其他」自定义选项，不再出现 unknown 或通用占位文案；卡片时间也恢复为真实发起时间。
- **消息不再丢失**：上一轮仍在运行时发送的消息会进入队列并在结束后自动发出，而不是被丢弃；队列发送失败后保持原有顺序；发送成功立即写入本地，缩小崩溃丢消息的窗口。
- **修复正文重复或缺失**：展开过程详情时，同一段正文不再出现两次；个别场景下最终答案不显示的问题已修复。
- **子代理显示真实名称**：自定义子代理的任务卡片现在能正确显示名称，不再一直停留在「子代理」。
- **多 Agent 房间更可靠**：重试投递保留完整对话上下文；重启后排队中的投递随房间打开自动恢复；修复若干事件归属边界。

## 长程任务

- **修复任务状态从未持久化**：此前长程任务的进度、阶段与中断恢复信息实际未写入磁盘，重启即丢失，现已修复。
- **修复任务可能提前终止**：未识别到总步数时，第一步不再被误判为「最后一步」。

## 界面与体验

- 过程流正文恢复富文本渲染（粗体、列表、行内代码），并修复段落间异常空行。
- 用户消息悬停显示发送时间，时间格式统一。
- Markdown 表格按内容自适应列宽，短字段优先单行显示。
- 项目内搜索精准定位命中内容，自动展开折叠层级并选中。
- 文件差异预览填满卡片；滚动条/滑块样式统一，输入框滚动条不再挤压正文；侧边栏会话结束后不再残留运行动画。
- 思考片段增量归并性能优化，长思考流更流畅。

## 附件与运行时

- **附件改为结构化传输**：本地文件作为正式附件随消息上传，会话历史中的文件卡片更完整。
- **内置 Kimi SDK 升级至官方 0.31**：继承上游自定义 Agents、插件能力、配额与工具循环修复。
