# Kimix v2.21.197

## 新功能

- 内置 Kimi Code 运行时升级至官方 0.42.0，继承官方近期的新能力与运行时改进（官方已移除旧版引擎，统一为新架构）。
- 背景信息窗口新增输出统计：平均缓存命中率、平均速度、本轮速度，模型效率一目了然（上下文用量指示处点开查看）。
- 引导（steer）内容滞留在官方队列时，气泡上新增「从官方队列取消」按钮，可单独摘除，避免轮次结束后被自动补跑（需内置运行时 0.42+）。
- 接入官方 Tower 协作编排（实验功能，默认关闭）：开启后由多个子 Agent 并行协作，右侧检查器实时展示任务进展，输入区「后台 Agent」胶囊支持状态筛选。
- 新增 `/自定义风格` 本地命令：一键向 Agent 发送界面风格设计要求，生成的风格文件写入收件箱后自动导入生效。
- 自定义界面风格可自带专属色彩方案，导入后自动启用；新增子 Agent 上下文 fork、消息自动折叠（默认开启）等实验开关。
- 新增选区标注：在消息流或文件预览中选中文字即可「引用到对话」，输入框中以独立引用块呈现。
- 权限模式对齐官方命名：始终询问 / 必要时询问 / 完全自动，切换到有风险的模式时会明确提示。
- 通知卡片补充来源署名，区分子代理与后台任务；新建会话后侧栏自动滚动定位到该会话。
- 对话输入框的 `@文件` 搜索在内置运行时会话中使用官方文件建议引擎。

## 修复与优化

- 修复老会话正文缺失/不全的多个根因：超长会话历史现在通过官方分页接口完整加载（此前只取最近 100 条，早期内容丢失）；被打断的轮次正确收口，正文不再与下一轮混杂；贴过图片的会话重启后截断的正文可自动恢复。
- 修复后台任务（如长期运行的服务）把已完成会话持续显示为「运行中/执行中」的问题。
- 修复后台任务完成通知位置错误、同一轮被错切成两张「输出完成」卡片、通知重复显示的问题。
- 修复「本轮总耗时」虚高的问题：被中断轮次不再把离开间隔计入；超过 1 小时显示为「x小时x分x秒」。
- 修复历史会话图片显示占位符或无法打开的问题，历史图片按官方内容寻址流式显示。
- 修复已结束的旧会话重启后仍显示「执行中数百分钟」、压缩摘要多处重复气泡、缓存过期弹窗误发回旧会话等问题。
- 安装包瘦身：Windows 安装包从约 123MB 降至约 108MB；本地翻译运行时改为首次使用时按需下载。
- Windows 窗口圆角、任务栏图标、设置页边缘留白等一系列界面一致性问题修复；自定义风格覆盖更全面。
- Kimi Code 配置改为原子保存；YOLO 模式不再静默放行危险命令。
- 升级后首次打开历史会话会一次性校正本地缓存，可能略慢，属正常现象。

## 已知边界

- 「从官方队列取消」需要内置运行时 0.42 及以上；使用旧版外部运行时时会提示不支持。
- Tower 为实验功能且默认关闭，开启后由官方运行时操作 Git 工作区；清理（Teardown）需工作区无未提交改动。
- 本地翻译首次使用需要联网下载运行时组件；已安装过的老用户不受影响。
- 危险命令防护策略由官方 Kimi Code 提供，可在其 `config.toml` 的 `[permission]` 中调整。
