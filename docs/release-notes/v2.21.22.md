# Kimix v2.21.22

## 对话输出

- 修复流式正文在状态刷新、完成回放和历史修复之间被截断、重复或短暂显示两份的问题。
- 完成回放改为按稳定消息身份原子替换，保留完整正文、思考内容和处理时长。
- 修复完成态 Markdown 把正文单换行折叠成空格的问题；诗歌、逐行说明和其他有意换行的内容在流式与完成态保持一致。
- 完成回放不再人为插入额外换行，避免短句、代码和列表被拆成断断续续的行。

## 模型配置

- 收紧思考档位探测：网关只接受参数但不代表模型支持时，不再误报为全部档位。
- 思考档位改为按供应商和模型目录匹配，避免同名模型串档；模型上下文上限可独立从目录回填。
- 目录信息缺失时，可复制不含 API Key 的 AI 核对提示，询问供应商、模型上下文和实际思考档位。
- OpenAI 兼容线路的 `max` / `xhigh` 档位展示与发送值保持一致。

## 设置与界面

- 修复侧栏拖拽柄占据布局列造成的固定宽缝，拖拽热区覆盖真实边界且不再抢占边缘滚动条。
- 设置页侧栏、搜索框和导航项随拖拽宽度自适应，右边界保持对齐。
- 统一对话折叠触点、复合按钮分割线和内容容器圆角的视觉契约。
