# Kimix v2.21.122

## 新功能

- Windows 透明窗口外缘新增跟随圆角的细描边，浅色桌面背景下窗口边界更清晰；最大化和全屏时自动隐藏。

## 修复

- 修复部分设备上任务栏按钮显示系统默认图标的问题。打包版本的任务栏图标与分组身份现在始终使用 Kimix 图标。
- 修复插件页安装 Kimi WebBridge / Kimi 计算机使用能力时偶发卡在“部分就绪”的问题。安装前应用会先结束自己占用的能力二进制进程，安装不再因文件被占用而中断。
- 修复能力安装预清理范围过大的问题。预清理现在只结束本应用自己启动的进程，不会误伤其他程序正在运行的同名组件。

## 已知边界

- 能力二进制若正被其他非 Kimix 程序占用（如同时运行其他 Kimi 系工具），预清理会选择保留该程序进程，安装仍可能显示“部分就绪”；关闭占用程序后再安装可恢复。
