# Kimix v2.20.1

本版本从 v2.19.5 起算，是一次大规模根治版本，聚焦启动卡顿、历史轮次正文消失、消息拼接错乱与事件顺序错乱四个问题。

## 启动性能

- **增量持久化**：会话数据改为按会话分键存储，每次自动保存仅写入发生过变化的会话。大量会话的场景下单次保存耗时从 1-13 秒降至接近 0 毫秒（无变化时完全跳过）。
- **修复循环限流**：修复循环在遇到官方历史被本地保护逻辑拒绝（如缺少工具调用帧）时，不再每秒重复尝试 15 次，改为仅当官方历史实际增长后才重试一次。
- **避免不必要的自动保存**：消除因数组引用变化但内容未变的假变化触发的自动保存；启动窗口内的归档/删除操作合并到防抖队列，不再频繁写入磁盘。

## 历史轮次修复

- **正文消失根治**：修复历史对话中正文在多步工具调用后丢失的问题——此前部分轮次只显示模型名和工具卡片、正文不见，现在正文完整显示；工具调用与正文按实际顺序穿插呈现，与官方 Kimi Code 网页版一致。
- **正文乱序修复**：修复第三方模型（如 grok-4.5）消息正文片段乱序到达时产生的文字拼凑错乱问题（如"你好"被拼成"霖江路…你好"）。
- **事件顺序修复**：修复部分轮次正文只显示开头一两句预告、完整回答被折叠在过程摘要中的问题；已持久化的会话数据在应用启动时会自动修复。
- **排除多余空帧**：已完成轮次末尾不再残留多余的空完成标记事件。

## 其他

- 诊断日志完善，方便反馈问题时定位。

## 已知边界

- 旧存储格式的会话数据会在首次自动保存时迁移到新格式。若迁移写入失败，下次将继续重试，确保数据不丢失。
- 熔断机制存储在浏览器本地，最多保存 500 条记录；超过时自动淘汰最早记录，不影响正常使用。
