# v2.20.272 发布说明

> 覆盖自上一个正式版本 v2.20.145 之后的全部变更（含未发布的 v2.20.236 内容）。

## 后台任务与定时任务通知

- 新增后台任务/定时任务通知卡：任务完成、失败、丢失、定时任务触发都会在对话里生成通知，点击可展开类型、来源、正文与原始信息；连续多条通知自动聚合成「N 条通知」分组卡。
- 通知卡现在收进当轮「思考工具链」里按发生位置展示（空闲时到达的通知仍单独显示），样式跟随界面主题（现代/复古等），不再是一块突兀的蓝色块。

## 目标（Goal）与胶囊 Dock

- 输入区上方新增目标胶囊与弹窗：可直接查看当前 Goal 状态，并执行暂停、继续、取消、刷新；与后台 Bash、子 Agent、待办胶囊同一排展示。
- 输入区工具栏重构为官方式胶囊行：面板半透明+背景模糊、圆角与描边随界面风格分化、消息滚入输入区时向上淡出，不再遮挡聊天内容。
- 胶囊弹窗与侧栏后台任务块互斥：胶囊收起后任务块移到侧栏，从侧栏恢复后回到胶囊，不再两边同时出现。

## 跨客户端同步（官方 Web / 其他客户端）

- 修复在 Web 端已回答的提问，Kimix 里仍显示「待回答」：现在外部回答后卡片会自动变为已答（含连续追问、断线重连等场景）。
- 修复外部已回应的审批永久显示「待审批」。
- 修复外部新轮首段思考/正文丢失、早到工具帧粘到上一轮、启动时全量重放卡死、多轮合并、用户消息只剩最早一条等问题；Web 侧新建对话也会同步到 Kimix 侧栏。
- 权限模式在 Kimix 与官方 Web 双端同步。

## 消息队列与引导（steer）

- 排队消息锁定发送时的模型；上一轮失败/中断后排队消息不再自动发出，会提示「上轮已终止，N 条排队消息未自动发送」。
- 修复引导链路一系列问题：同一条引导被执行两遍、引导气泡永久「等待官方写入」、正文段落重复渲染、切分后出现两个可滚动区域与同文重复、发送后消息头误显「思考中」等。

## 流式渲染与历史对账

- 修复多步任务中「中间思考段消失、几十步工具粘成一张卡、正文只剩残片」：思考、正文、工具卡按官方顺序交错显示；已受损的旧会话轮末自动对账自愈。
- 修复同段重放导致完整正文被丢、跨轮错位导致上一轮正文缺失、输出完成后尾部大段空白。
- 修复思考工具链展开带动子内容一并展开、覆盖全文的思考块仍可展开。

## 运行状态与稳定性

- 修复子代理失败时主轮闪「输出完成/报错」、主轮结束仅剩后台任务时仍显示「消息处理中」、已结束会话残留停止按钮。
- 修复空闲会话每 90 秒无谓断连重连；Server daemon 静默故障周期自愈；单次会话级故障不再误杀整个后台服务。
- 修复运行中点击刻度跳转后跳回旧位置、滚动停止后视口自动下跳、流式期间思考/正文段错位。

## 模型与配置

- 修复新会话选中的模型被默认模型接管（显示 k3 却以 deepseek 执行）、选择器回跳；配置新模型后老会话无需重启即可使用。
- 添加模型时 Context 与思考档位按官方目录自动预填；轮中可预切换权限/plan/思考强度，下一轮生效。
- 修复当轮消息头/底部信息缺模型、轮末信息卡只剩模型名或混入通知文案。

## 体验与性能

- 流式思考卡顿优化（draft 订阅下沉叶子组件）；首次滚动卡顿优化（代码高亮移出渲染通道）；长对话渲染内存加上限保护。
- 崩溃/卡死页跟随当前主题；套餐用量时间条恢复翠绿；搜索浮层居中；代码块留白对齐官方 Web；悬停风格化全面补齐。
- Windows 通知点击正确聚焦窗口；通知点击跳转聚焦消息顶部。

## 已知边界

- 官方队列中尚未启动的消息无法从 Kimix 撤回（官方接口限制）；切换模型时已在官方队列的消息仍会按排空时的模型执行。
- 其他客户端拒绝的审批，Kimix 侧可能滞后到轮次结束才更新状态。
- 历史中极旧的受损会话若对账未覆盖，可切会话触发一次重载兜底。
