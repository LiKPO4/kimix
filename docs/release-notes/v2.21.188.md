# Kimix v2.21.188

## 修复与优化

- 修复后台任务完成通知的显示位置错误：轮次进行中到达的通知，现在正确折叠在该轮的过程链里，不会再作为独立卡片出现在正文下方；打开老会话时也不再把同一条通知重复显示。
- 修复同一轮被后台任务通知错切成两张「输出完成」卡片、思考内容被顶成正文的问题。
- 修复后台 Bash 任务仍在运行时，已完成的轮次被错误重开为「执行中」、正文暂时不显示的问题。
- 修复权限模式按钮文字被压缩省略的问题：「必要时询问」等模式名称现在完整显示。
- 升级后首次打开历史会话会一次性校正本地缓存（把旧版本错误保存的重复卡片、错切轮次恢复正常），可能略慢，属正常现象。
