# Kimix v2.21.118

## 新功能

- 自定义界面风格现在可以自带一套专属色彩方案。选择或导入风格后会自动启用对应配色；旧版未声明颜色的风格会自动使用项目默认色彩，不需要重新导入。
- 很长的用户消息发送后会自动折叠，并提供符合 Kimix 风格的展开/收起按钮；消息原文、附件、复制、导出和模型上下文仍保持完整。
- 界面风格现在可以控制窗口外壳圆角，内置风格和用户导入风格都能获得更一致的窗口轮廓。

## 修复

- 修复历史会话中的图片显示为文件占位或无法打开的问题。历史图片现在按官方文件标识流式显示，并支持多图切换、复制图片和打开画板。
- 修复 Kimi Server 未启动、重启或读取失败时，磁盘中仍存在的历史图片和视频无法显示的问题；自定义 Kimi 数据目录和旧版目录同样兼容。
- 修复带图片的用户消息末尾出现额外“[图片]”文字标记的问题。
- 修复恢复上次长草稿时输入框高度没有同步展开的问题。
- 修复用户清空输入框后退出应用，重新打开仍恢复已经删除文字的问题。
- 修复 Windows 窗口外缘出现异常包裹、窗口圆角与主内容区域不一致，以及任务栏显示 Electron 默认图标的问题。
- 修复设置页右侧滚动条、留白和窗口边缘不对称的问题。
- 修复切换默认模型时模型列表位置跳动、文件变更卡归属错误及悬停反馈不一致的问题。
- 修复用户导入风格未完整覆盖弹窗、菜单和检查器外壳的问题。

## 优化

- 升级内置 Kimi Code 运行时至 0.38，提升与当前官方能力和配置格式的兼容性。
- 历史媒体默认保持流式读取；只有复制、画板或流式加载失败时才按需读取完整图片，视频拖动仍按所需区间读取。
- 默认主题的窗口圆角和面板层级进一步统一，透明窗口边缘在不同桌面背景下更自然。

## 已知边界

- 历史图片或视频对应的本地文件已经被外部删除时，应用无法恢复其内容，会显示读取失败提示。
- Windows 透明窗口由应用界面绘制外壳，因此不使用系统原生窗口阴影；最大化和全屏状态仍保持直角边界。
