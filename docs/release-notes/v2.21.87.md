# Kimix v2.21.87

自 v2.21.75 起的累积更新。

## 新功能

- 新增「思考翻译」：可将 Agent 的英文思考内容近实时翻译为简体中文，并支持“仅显示中文”或“中英对照”。更新频率可在 1 秒、2 秒、2.5 秒、3 秒、4 秒和 5 秒之间选择。
- 思考翻译提供两种互斥方案：约 120 MB 的本地轻量模型下载后可离线运行，无需账号或 Key；也可使用自己的 Microsoft Translator 凭据进行云端翻译。两种方案都可随时关闭。
- 输入框上方的工作胶囊对齐官方 Kimi Code：补全「计划」胶囊，并统一目标、计划、后台 Bash/任务、子 Agent、当前进度和消息队列的状态与计数展示。
- 计划面板现在直接显示当前官方会话保存的完整 Markdown 计划，内容较长时可在面板内滚动查看。

## 修复

- 修复首次打开历史会话时计划内容为空、必须切换会话后才出现的问题；冷启动会在官方会话完成绑定后自动补读。
- 修复官方 Server 会话可能误读其他会话全局本地 Plan 的问题；Server 会话现在只显示自身 transcript 中的计划。
- 修复长会话或复杂房间作用域下，本地思考翻译请求因标识过长而被拒绝、最终只显示英文原文的问题。
- 修复 Swarm 子代理受完成先后影响显示为 `#3、#1、#2` 的问题；现在始终按官方编号从小到大排列。
- 修复子代理模型池编辑行在「设为默认」时被按钮撑高的问题，并补齐胶囊文案、图标和运行中状态的细节一致性。
- 更新压缩包处理、本地模型运行时与配置校验相关依赖，修复已公开的高危安全问题。

## 隐私与已知边界

- 思考翻译默认关闭。本地方案只在首次下载模型时联网，下载完成后的翻译在设备上运行；云端方案会把当前可见的思考片段发送给 Microsoft Translator。
- 本地模型以快速、可读为目标，精度低于大型云端翻译服务；首次加载模型可能比后续翻译更慢。
- Microsoft Translator 需要用户自行准备订阅密钥；Kimix 使用系统安全存储保存凭据，不会把明文 Key 暴露给渲染界面。
