# Kimix v2.21.0

本版本从上一个实际发布版本 **v2.20.272** 起算，重点带来自定义界面风格导入、插件页重组、Goal 与 SDK v2 稳定性增强，以及模型思考档位和对话体验改进。

## 自定义界面风格

- 设置 → 外观现在支持导入 **UI Style v1 JSON**，可自定义圆角、边框、层次、控件材质与交互动效，并随当前明暗主题和配色方案工作。
- 内置的默认、现代、复古、怀旧风格继续受到保护；自定义风格可以导入、切换和删除，删除当前风格后会安全回到默认风格。
- 新增「复制 AI 提示」入口，可让具备文件能力的 Agent 直接生成可导入 JSON 文件；导入前会严格拒绝任意 CSS、选择器、URL、脚本和越界字段。
- 全面补齐按钮、菜单、侧栏、弹窗、输入区、消息操作等触点的静止、悬停、按下、选中与聚焦状态；统一 Composer 工具栏和消息复制操作尺寸。
- 风格卡统一为单行固定高度，描述最长 48 个字符；历史长描述会自动兼容迁移。

## 插件与能力管理

- 插件页 Skills 重组为「本地 / 商店 / 运行时」三个子页，本地 Skill 按名称去重，并展示官方内置能力。
- MCP 页面移除固定宽度侧栏，将配置与连接状态合并为顶部信息区，窄窗口下更易浏览。
- 修复插件页异步请求竞态，快速切换页面时不再被较早返回的数据覆盖。

## 对话、Goal 与运行状态

- 官方 Goal 状态可实时同步；续跑提示不再伪装成用户消息，而是折叠为「目标续跑」状态摘要。
- 修复后台子 Agent 或残留工具阻塞当前轮结束、压缩状态重复、流式思考首句脱离后续内容、折叠后正文偶尔只剩标点等问题。
- 修复官方压缩活动链与终态识别，在缓存长时间闲置时可于发送前提示压缩；该提示可在设置中开关。
- 侧栏会根据官方轮次结束原因更准确地标记失败或忙碌状态，MCP 已移除状态也不再误显示为「未连接」。

## 模型与思考档位

- SDK 路由默认升级到 v2 引擎，并更新内置 SDK；保留环境变量回滚入口，便于兼容特殊环境。
- 思考档位词表与上游对齐，支持 `xhigh`，不再错误降级为 `max`；未知支持列表的模型也可在配置阶段正确矫正档位。
- 设置页新增思考档位「自动探测」，切换模型时会同步采用新模型的默认思考强度。
- 运行中切换思考强度会预设到下一轮，不再被静默忽略。

## 体验与性能

- 新增对话刻度显示开关，可选择左右位置和宽度；设置项收为紧凑单行布局。
- 启动恢复减少重复目录扫描，并行加载会话数据，提升多项目、多会话环境下的启动速度。
- 数字输入框支持正常的逐键编辑中间态，不再因即时截断而吞掉输入。
- 侧栏 Git 卡重新排布刷新、图谱和推送操作；项目与会话随行按钮只在单个操作被悬停或聚焦时显示材质。
- 修复各界面风格下「打开项目」加号的裁切、悬停反馈，以及归档、删除、重试、外链等次要操作未正确跟随自定义材质的问题。

## 已知边界

- UI Style v1 只负责形状、边框、层次和动效，不允许覆盖颜色、字体、间距或布局；这些仍由 Kimix 的主题与产品布局统一管理。
- 从旧版本载入的自定义风格描述若超过 48 个字符会自动截断；新导入文件超过上限会直接拒绝并提示修改。
- SDK v2 若与特殊本机环境不兼容，可设置 `KIMIX_SDK_ENGINE=v1` 临时回滚。
