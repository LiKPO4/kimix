# Kimix v2.20.45

本版本从 v2.20.41 起算，包含流式重复修复与两处易用性改进。

## 流式输出

- **修复部分轮次正文/内容在实时流与历史回放之间重复出现的问题**：实时草稿与官方历史回放现在按同轮语义正确合并与去重，不再出现同一段内容显示两遍或重复物化；已受影响的本地会话数据在启动时自动修复。
- 保留官方会话的模型归属；自动压缩失败时给出明确提示而不是静默。

## 更新记录与模型供应商

- **更新记录格式统一**：Kimix 本体卡与 Kimi Code 卡统一为「当前：x · 最新可安装：y」；并移除卡片与版本条目上的日期显示，避免窄栏换行。
- **本地代理模型探测更友好**：当第三方供应商的 Base URL 是只转发对话、未实现模型列表接口的本地代理时，探测会提示「该 Base URL 未实现模型列表接口，可手动添加模型」，不再显示为探测失败。
