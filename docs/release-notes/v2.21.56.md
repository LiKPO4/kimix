# Kimix v2.21.56

## 套餐用量与月度额度

- 套餐用量小窗新增月度总额度与赠送额度查询，可在设置中选择开启。
- 支持通过内置 Kimi 登录窗口自动获取网页凭证，并保留独立网页登录会话；后续查询会在后台按需续期，减少重复登录。
- 月度额度凭证改为以会员接口实际验真结果为准，不再把 JWT 显示的到期日期误当作服务端仍然有效。
- 修复登录完成后仍停留在“等待登录”、刚配置即提示过期、有效凭证被会员接口拒绝，以及旧凭证验真时遗漏新凭证的问题。
- 自动登录会校验网页账号与当前 Kimi Code 账号，避免错误展示另一账号的额度。

## 会话与操作稳定性

- 新会话尚未连接运行时也可配置模型、权限、Plan、思考强度和 Swarm；首次发送时再创建并应用运行时配置。
- 修复新会话仅发送普通问候却把工作区已有改动统计成本轮 154 个文件变更的问题；文件变更现在只统计本轮可信增量。
- 修复移除房间内 Secondary Agent 后，输入区仍保留房间提示或错误状态的问题。
- 优化会话启动与切换时的后台任务读取，减少后台 Bash 状态和启动任务出现数秒延迟的情况。

## 界面与交互

- 外观设置按职责重新分组，界面风格、字号和对话刻度不再混放。
- 结构化提问卡纳入 Agent 思考工具链，并保持回答选项、选中态和自定义输入框的主题样式一致。
- 文件变更预览在“未找到差异”状态下也能正确显示展开箭头，并可再次点击收起。
- 自定义导入风格的普通按钮默认保持克制，只在悬停、展开或选中时强调；Swarm 等开启态继续保留清晰的浮雕反馈。
- 统一折叠卡片、过程行和套餐用量刷新按钮的圆角、阴影与尺寸稳定性。

## 已知边界

- 月度与赠送额度依赖 Kimi 网页会员接口。首次启用需要在内置窗口登录；若该独立网页会话本身已退出，仍需重新登录。
- 月度额度属于可选增强项；查询失败不会影响 Kimi Code 原有的 5 小时和每周套餐用量显示。
