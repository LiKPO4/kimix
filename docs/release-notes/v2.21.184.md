# Kimix v2.21.184

## 新功能

- 内置 Kimi Code 运行时升级至官方 0.41.0，继承官方近期的新能力与运行时改进。
- 新增选区标注：在对话消息流或右侧文件预览/Diff 面板里选中文字，会弹出「引用到对话 / 评论」浮层，一键把选中内容带进输入框（对齐官方 0.41 web）。
- 选区引用在输入框里以独立的引用块（chip）形式存在：显示摘录、可单独删除，发送时自动转为标准引用格式，与官方形态一致。
- 权限模式改用官方 0.41 命名：始终询问 / 必要时询问 / 完全自动；切换到后两种模式时会提示文件可能被直接修改或删除。

## 修复与优化

- 安装包明显瘦身：剔除本地翻译组件中与本机架构无关的原生库和 DirectML 冗余，Windows 安装包从约 123MB 降至约 108MB。
- 本地翻译运行时改为首次使用时按需下载，不再随安装包全量打包。
- 修复部分老会话重新打开时正文缺失、与官方 web 显示不一致的问题：被打断的轮次现在能正确收口，正文不再和下一轮的开头混在一起。
- 修复老会话中「本轮总耗时」虚高的问题：被中断轮次的耗时不再把两轮之间的离开间隔算进去（之前可能显示数小时，实际只工作了几分钟）。
- 耗时显示格式优化：超过 61 分钟时显示为「x小时x分x秒」，1 小时以内仍保持「x分x秒」。
- 升级后首次打开历史会话会一次性刷新本地缓存，可能略慢，属正常现象。

## 已知边界

- 本地翻译首次使用需要联网下载运行时组件；已安装过的老用户不受影响。
- 危险命令防护策略由官方 Kimi Code 0.41 提供，可在 Kimi Code 的 `config.toml` 中通过 `[permission]` 配置调整。
