# Kimix v2.21.175

## 新功能

- 内置 Kimi Code 运行时升级至官方 0.40.1，继承近期的运行时稳定性、会话 fork 与配置处理改进。
- Tower 模式跟进官方 0.40 语义：开启时使用当前 Git 分支作为基础分支，首次创建任务分支时会带入工作区的未提交改动快照；合并前仍会保护可能被覆盖的本地改动。
- 对话输入框的 `@文件` 搜索在内置运行时会话中使用官方文件建议引擎，能力不可用时继续回退到本地搜索。

## 修复与优化

- YOLO（自动通过）模式不再静默放行危险命令或敏感操作；普通工具仍可自动批准，运行时要求确认的操作会正常显示审批卡片。
- Kimi Code 配置改为原子保存，避免后台运行时在写入过程中读到空白或不完整配置。
- 修复后台任务完成后通知轮正文缺失、会话重新卡在“消息处理中”的问题；后台结果现在会通过权威快照补齐并归入正确轮次。
- 自定义风格的交互态边框改为预留恒定宽度，按钮悬停或按下时不再发生尺寸跳动、挤压相邻内容。
- 统一右侧会话面板、Diff 面板与主区域的圆角来源；会话侧栏开关补齐展开、收起两态图标和辅助文案。
- 修复折叠侧栏导航图标的颜色、尺寸、纵向节奏和水平居中问题；Hooks 图标按实际墨迹中心校正，设置导航图标不再被展开态布局挤压变形。
- 底栏错误状态不再永久显示历史轮次中的旧错误：同一 Agent 的对话继续推进后自动恢复正常状态，当前错误也可点击确认关闭；历史错误卡仍保留供追溯。

## 已知边界

- 危险命令防护由官方 Kimi Code 0.40 提供；如需改变其策略，可在 Kimi Code 的 `config.toml` 中调整 `[permission]` 配置。
- 自定义风格只接受 UI Style v1 JSON，不执行任意 CSS、脚本、网络资源或布局改写。
