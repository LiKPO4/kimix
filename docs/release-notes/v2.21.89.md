# Kimix v2.21.89

## 修复

- 修复 Windows 自动更新无法下载的问题：此前发布流程中安装包文件名与更新清单（`latest.yml`）不一致，导致应用内自动更新下载 404、提示“缺少校验值”并跳转发布页。本版起更新链路已修复，并新增发布前校验，防止此类问题再次出现。
- 修复校验文件（`SHA256SUMS.txt`）中带空格文件名解析失败导致的更新校验缺失问题。

## 优化

- 安装包体积显著减小：移除了打包时误夹带的非当前平台翻译引擎二进制（此前 Windows 安装包约 170 MB，本版约 110 MB），macOS / Linux 同步受益，减小下载与安装耗时。
- 本地思考翻译功能不受影响，仍为可选开启。

## 已知边界

- Linux 安装包体积仍较大（约 400 MB 量级），后续版本继续优化。
