# Kimix v2.20.4

本版本从 v2.20.1 起算，包含模型切换行为修正与对话流显示修复。

## 模型切换

- **欢迎屏切换模型只影响下一个新会话**：此前在欢迎屏底部切换模型会直接修改全局默认模型。现在欢迎屏的模型选择仅作为"下一个新会话"的临时选择，新会话创建后即失效；全局默认模型请在「设置 → 模型供应商」中修改，不再受底部切换影响。

## 对话流显示

- **正文段不再闪现后消失**：流式输出期间，正文片段此前会先在正文区短暂出现、待工具调用到达后又被收进折叠（反复闪现）。现在运行中的正文段全程保留在折叠的过程详情里，轮次完成后最终答案一次性显示在底部，过程更清爽。
- **历史对话正文与顺序进一步修复**：修复部分历史轮次正文完整回答未显示、仅显示开头预告的问题。

## 其他

- 诊断与稳定性改进。
