# Kimix v2.21.222

## 新功能

- **Windows 11 窗口材质（Mica）**：设置 → 外观 → 显示与阅读新增开关。开启后窗口背景使用系统 Mica 材质，侧栏与顶栏半透明透出桌面，四角由系统绘制；仅 Windows 11 可用，开启或关闭后需重启 Kimix 生效。

## 修复与优化

- **彻底修复大会话的切换与打开卡顿**（多日专项排查的最终成果）：往返切换、从设置页返回不再出现秒级冻结；此前每次切换都会重复一次约 0.8–0.9 秒的历史对账，现已消除。首次打开超大会话（数百事件、单轮多子代理、二十余万字思考）仍有一次约 2 秒的合并，同一次运行内只会发生一次，之后任何切换都直接命中缓存。
- 侧栏会话/项目行的悬停操作按钮反馈统一：普通操作悬停显示深一档灰底 + 描边（不再与整行悬停背景融为一体），仅「删除」保留红色。
- 会话「…」菜单整理：移除置顶对话、打开侧边聊天、添加自动化、在新窗口中打开四个无实现的占位项；「导出 Kimi 调试包」与「删除对话」（红色）从侧栏悬停按钮移入菜单，悬停按钮组现在只保留「导出 Markdown」与「归档」。
- 修复已完成轮次在特定上下文下显示不刷新的问题（渲染缓存键补充上下文维度）。

## 已知边界

- Mica 窗口材质仅 Windows 11（build 22000 及以上）可用且需重启生效；开启后窗口四角改用系统圆角（与默认形态的 CSS 圆角略有差异）。
- 首次进入超大会话的一次性合并耗时（约 2 秒）尚未消除，但同一次运行内不会重复。
