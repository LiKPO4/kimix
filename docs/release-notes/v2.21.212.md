# Kimix v2.21.212

## 新功能

- **会话标题自动生成**：首轮对话结束后由 AI 生成会话标题并显示在侧栏；重命名对话框输入框右侧新增「重新生成」按钮（✨），可随时让 AI 换个标题再保存。
- **会话可删除**：侧栏会话悬停出现删除按钮，确认后永久删除该会话及其对话记录（此前仅支持归档）。删除操作不可恢复。
- **日志录制**（设置 → 诊断）：可一键录制含卡顿信息的运行日志，默认 5 分钟、随时手动停止并保存；新增「下次启动自动录制」一次性开关，重启后在窗口创建前自动录制启动后前 1 分钟，适合排查启动卡顿；录制结束弹出系统通知，点击可直接打开文件所在文件夹。
- **Markdown 元信息卡片**：以 `---` 开头的 YAML frontmatter 元数据（标题、日期、标签等）渲染为键值卡片，数组值显示为标签胶囊。
- **目标时间显示**：Goal 面板新增时间预算展示（有预算显示「已用 / 预算」，无预算显示已运行时长）。
- 设置 → 权限模式新增「不注入权限模式提醒」开关：开启后不再向模型上下文注入自动权限模式说明。
- 设置 → 常规新增「上下文压缩」配置：压缩请求失败时的最大总重试次数（对应官方 `loop_control`，默认 5）。
- MCP 服务添加表单新增「按需加载工具（deferred）」开关：开启后该服务的工具不进入顶层列表，由模型按需加载（需开启「工具按需加载」实验且模型支持动态工具加载）。

## 修复与优化

- **根治大会话卡顿**：数百事件、单轮多子代理、长思考（20 万字级）的会话打开/切换不再出现数秒冻结；流式输出期间的滚动与界面响应同步改善（渲染与事件合并全链路优化）。
- **修复套餐用量「5小时 / 本周」显示 0%**：官方用量接口结构变更导致解析失败，现已适配恢复（月度与赠送额度不受影响）。
- 更新记录弹窗的「浏览器查看」在更新进行中、检查中也可点击（此前被禁用变灰）。
- 官方 Kimi Code 引擎升级至 0.43.1：带来子代理内存释放、并发子代理事件循环优化、每轮渲染渐进变慢修复、重试崩溃修复等可靠性改进；`rm -rf` 仅针对 /tmp 类临时目录时不再反复弹确认。
- 模型管理列表对配置文件中缺失 model 字段的条目显示「缺少 model 字段，无法使用」警告，不再静默回退显示别名。

## 已知边界

- 「重新生成标题」暂不支持托管官方 Server 的会话（使用兼容链路的会话可用）。
- 「月度与赠送额度」依赖设置中配置的网页 Token，Token 过期后需重新配置。
- 删除会话为永久删除（官方侧与本地同时删除），请与归档区分使用。
