# Kimix v2.21.75

自 v2.21.56 起的累积更新。

## 新功能

- 设置新增「子代理」页：可配置子 Agent / Swarm 的模型池——默认模型、锁定模式、每个模型的选择提示与思考强度，编辑后自动保存。配合官方 Kimi Code 0.36，主 Agent 派子 Agent 时会参考池内提示挑选模型，适合把搜索、探索、批量写内容等粗活交给快速便宜的模型。
- 新电脑缺少 Git Bash 时，对话失败会自动弹出引导弹窗：说明原因、支持 winget 一键安装 Git for Windows，也可打开官网下载或复制安装命令。
- 设置「账户与连接」新增两张状态卡：Git Bash 运行环境、Server 发送通道。Server 不可用时能看到具体失败原因并一键重试。
- 消息经 SDK 兜底发送时，状态栏会带上 Server 不可用的原因摘要，不再只有干巴巴的「经 SDK 发送」。
- 官方内置能力（Kimi Computer Use / WebBridge）安装过程显示实时进度（步骤与百分比），安装失败会保留失败原因并可继续安装。
- 插件页支持登记「官方附加 Skill 目录」（Kimi Code `extra_skill_dirs`），在用户、项目和插件 Skills 之外追加发现源，不替换默认目录、不复制文件。

## 修复

- 内置 Kimi Code 运行时升级到官方 0.36.0：修复 OpenAI 兼容供应商在思考被打断后每轮请求都报 400、插件根目录普通 Markdown 被误判为 Skill、MCP OAuth 凭证变更后连接不刷新等问题。
- 文本输入框的焦点（选中）状态现在跟随界面风格化（内置与导入风格均覆盖），此前部分输入框在任何风格下都是同一个蓝色焦点框。
- 设置搜索框聚焦时不再出现与外框风格不一致的内层描边，光标上下被裁切的问题一并修复。
- 对话尾部的文档卡与文件变更卡整体压缩高度，正文不再被大块卡片顶出视口；压缩后各按钮热区仍符合规范。
- 模型与供应商页补上「模型配置」标题；子代理页内容上下拉满，不再留大片空白。

## 已知边界

- 子 Agent 模型池需要本机 Kimi Code 0.36.0+ 才生效；Kimix 托管运行时已内置 0.36。
- 锁定模式（force）开启时池条目不保存，界面会隐藏条目列表并给出说明。
