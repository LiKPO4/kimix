# v2.20.236 发布说明

> 覆盖 v2.20.145 之后的全部变更。

## 流式渲染与历史对账（本轮重点）

- 修复了多步任务中「中间思考段消失、几十步工具粘成一张卡、正文只剩残片」的系列问题：根因是流式偏移量按步重启而客户端按整轮累计，提交边界未清理锚点导致后续整段被误判为回放丢弃。现在思考、正文、工具卡按官方顺序交错显示。
- 历史中已受损的旧会话可自愈：轮末自动对账会按轮补回残片正文、折叠重复的思考/正文材料化事件，重复堆积的旧思考段不再固化。
- 修复跨轮错位导致的「上一轮正文缺失」：下一轮开头的内容误落到上一轮边界下时能正确归位。

## 消息队列与引导（steer）

- 排队消息锁定发送时的模型：排队期间切换模型，补发不再被静默换成新模型。
- 上一轮失败/中断后，排队消息不再自动发出，会显示「上轮已终止，N 条排队消息未自动发送」提示，由你决定何时继续；正常完成的轮次仍自动续发。
- 修复引导（steer）失败时同一条内容被执行两遍（出现两个一模一样的回复）。
- 修复引导气泡永久停在「等待官方写入」：轮次结束时已确认的引导会正确定格。
- 修复轮次显示完成后排队消息不派发的两个堵点（过期提问、官方队列终态残留）。

## 跨客户端同步（官方 Web / 其他客户端发起的轮次）

- 修复外部新轮首段思考/正文丢失、早到工具帧粘到上一轮、启动时全量重放风暴卡死等问题；外部新轮的用户边界与早到帧现在按正确顺序补全。
- 外部已回应的审批不再永久显示「待审批」。

## 运行状态与终态

- 修复子代理失败时主轮闪「输出完成/报错」约半秒的假终态。
- 修复空闲会话每 90 秒无谓断连重连。
- 修复主轮结束仅剩后台任务时仍显示「消息处理中」；修复已结束会话偶尔残留停止按钮。
- Server daemon 静默故障时周期自愈，SDK 兜底窗口压缩。

## 模型与配置

- 修复新会话选中的模型被默认模型接管（显示 k3 却以 deepseek 执行）、选择器回跳。
- 配置新模型后老会话无需重启即可使用；轮中预切换权限/plan/思考强度在下一轮生效。
- 修复当轮消息头/底部信息缺模型、轮末信息卡只剩模型名。

## 体验与性能

- 修复运行中点击左侧刻度跳转约 1 秒后跳回旧位置。
- 修复流式期间思考/正文段跳到工具帧前的错位。
- 首次滚动卡顿优化：代码高亮移出渲染通道，快照同指纹重放风暴跳过。
- 崩溃/卡死页跟随当前主题；套餐用量时间条恢复翠绿；搜索浮层居中、代码块留白对齐官方 Web 等多项视觉修正。

## 已知边界

- 官方队列中尚未启动的消息无法从 Kimix 撤回（官方接口限制）；切换模型时已在官方队列的消息仍会按排空时的模型执行。
- 历史中极旧的受损会话若对账未覆盖，可切会话触发一次重载兜底。
