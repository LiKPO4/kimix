# Kimix v2.20.41

本版本是 **v2.17.1 之后的大型更新**：主线是对齐官方 Kimi Code 网页版的**实时流式体验**（思考与正文全程逐字可见、长思考五行内滚、落盘摘要、任务/提问/工具卡一致化），并根治启动卡顿、历史轮次正文消失与拼接错乱、归档管理等一批长期问题。（v2.20.0 / v2.20.1 / v2.20.4 曾编写说明但未实际发布，其全部内容已并入本版本。）正式包仍由 **GitHub Actions** 构建发布。

## 实时流式体验（本版主线）

- **思考内容实时逐行显示**，不再等待数十秒后整段跳出：实时订阅静默约 8 秒自动探测恢复、90 秒硬上限重连，发送新消息后立即重建订阅；重连后的快照与新事件错序、无 offset 思考片段错拼均已修复。
- **长思考超过五行变为内部可滚动区域**，自动跟随最新一行，向上滚动即暂停跟随、回到底部恢复；完整思考始终可回看（已移除 2000 字尾部截断）。
- **思考落盘为摘要**：已走完的思考阶段收成尾部摘要（多段取尾段、长单段取最后一行），点击可展开查看全文；只有仍在生长的最新阶段保留五行实时滚动。
- **最终正文流式输出**：最后一个工具结束后，答案逐段增长而不是结束瞬间一次出现；运行中的过渡短句全程留在过程流原位置（黑色主文本、不折叠、不搬进搬出），轮次完成后最终答案归位正文区且只出现一份。
- **流式期间实时渲染 Markdown**：标题、加粗、代码等格式随输出渐进呈现（约 0.3 秒一拍、滚动时自动让行），不再全程显示原始符号；如需回退纯文本可在 localStorage 设置 `kimix_streaming_plain_markdown=1`。
- **正文顺序与完整性**：正文片段按官方 offset 锚定装配（根治 grok 等模型乱序到达导致的"霖江路…你好"式拼凑错乱）；实时草稿提交按真实到达顺序（修复"霖江路。你好"式段内乱序）；含工具调用的轮次结束时最终正文完整显示，不再只剩工具前的一小句；思考在轮次完成瞬间不再闪烁。

## 工具、提问与任务卡

- **失败的工具调用显示 ✗ 并标注「有失败」**（此前一律绿色对勾）；成功工具仍显示 ✓。
- **提问卡片落在过程流中的实际位置**，与工具卡同款样式：折叠显示"提问 · N 个回答"，展开可见问题与全部选项、已选答案打勾；待回答的提问仍保持底部交互卡。
- **单次 Agent 委派显示为「任务」卡**：可展开查看**完整委派指令全文**、子代理内部活动与结果摘要（此前只有进度条，看不到委派了什么）；多个并行委派保留 Swarm 组卡。**恢复/重载历史会话后任务卡不再退化为普通工具卡**。

## 启动与运行性能

- **增量持久化**：会话数据按会话分键存储，自动保存只写入有变化的会话；大量会话场景下单次保存耗时从秒级降到接近 0，启动后首次无变化保存完全跳过。
- **修复循环熔断**：官方历史被本地保护拒绝时不再每秒重试 15 次，仅在实际增长后重试一次；指纹覆盖 thinking 与用户图片，补回内容时自动放行重试。
- 启动窗口持久化防抖、hydration 引用守卫、启动性能采集器，以及多轮审查修复（大文件变更统计阈值、图片引用收集、GC 引用保护）。
- 实时连接解锁官方 volatile 推送（client_id 握手），连接假死自动检测重连。

## 历史对话与恢复

- **历史轮次正文消失根治**：正文跨工具调用不再被错误合并/吞没，单文本块误判、缓存映射刷新（v18）一并修复；存量错乱数据启动时自动修复。
- 缺失的最终正文可从官方历史补回；重启后正文、思考与过程流完整保留；长会话历史不再因 100 条快照窗口显示不全。
- 重试/中断后实时流式自动恢复；重试错误消息路由与成功确认修正；轮次真实耗时完整显示（含恢复的历史轮次）。
- 运行中与完成后的过程切分规则统一，消除视觉错位与跳跃。

## 模型与配置

- 模型上下文窗口表更新至各厂商最新两代（k3/k2.7-code、glm-5.2/5.1、gpt-5.6、claude-5/4.8、gemini-3、qwen3.7、grok-4.5），并按当前模型显示真实上下文窗口；模型探测可自动提取 Context Size。
- 子代理模型路由迁移到官方 0.29.1 `[secondary_model]`：配置卡片放回会话侧栏，写入去重（修复重复 section 导致会话报错），使用外部 Server 时提示该配置不生效，保存时校验思考档位合法性。
- **欢迎屏切换模型只影响下一个新会话**，不再直接修改全局默认模型（全局默认请在「设置 → 模型供应商」中修改）。
- 上下文压缩：等待压缩终态并统一反馈，存量压缩用量恢复显示。

## 归档与界面

- **归档面板全新改版**：搜索（标题/项目路径）、排序切换（归档时间/创建时间/按字母）、按工作区分组与筛选、每条显示时间、计数去重；恢复归档后可直接「打开该对话」。误归档的会话 24 小时后自动恢复。
- 左侧刻度轨：点击跳转转顶部对齐、高亮游标平滑滑动动画、置顶命中算法修正。
- 文件卡新增打开方式下拉（系统打开/显示路径/复制路径）并修复菜单层级；空状态建议扩充至 5 项并新增"快速了解项目"；权限模式文案与官方网页版统一；补齐官方 0.29 斜杠指令（内置 Skill 命令与本地 UI 命令）；后台任务/定时信封不再误显示为用户气泡；图片上传失败自动回退内嵌发送。

## 已知边界（请知晓）

- 流式期间的 Markdown 渲染为节拍式（约 0.3 秒），未闭合的加粗/代码块可能短暂显示原始符号，下一拍自愈；长答案下若感到滚动卡顿，可按上文开关回退纯文本流式。
- 归档时间仅本机归档过的会话为真实「归档于」，其余显示「最后活动」（官方 Server 暂未提供归档时间字段）。
- 恢复的历史轮次中，子代理的内部执行过程不可见（官方历史不含内部帧），任务卡展示完整委派指令与结果摘要。
- 子 Agent 独立模型依赖实验双模型路由；与官方自定义 Markdown Agent（agents/*.md）在 0.29 上不可兼得（内置 explore/coder/plan 不受影响）。
