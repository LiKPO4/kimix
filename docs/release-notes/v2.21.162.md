# Kimix v2.21.162

## 新功能

- 新增 `/自定义风格` 本地命令：直接向 Agent 发送完整的界面风格设计要求，并引导其把生成的 UI Style JSON 写入 Kimix 风格收件箱。文件写入后会自动导入并启用，无需再手动选择 JSON；设置页仍保留「导入 JSON」和「复制 AI 提示」入口。
- 新会话创建后，侧栏会自动滚动并将它定位到可视区域中央，项目和会话较多时也能立即找到。
- 通知卡片补充官方来源署名，明确区分子代理与后台任务，并显示对应 ID、结束状态和输出文件信息。

## 修复与优化

- 修复已经结束的旧会话在重启后仍显示「执行中数百分钟」的问题；恢复会话时以新进程获得的实时终态为准，不再用历史活动残留持续计时。
- 修复上下文缓存过期弹窗选择「开启新会话」后，提示词仍被发送回旧会话并触发压缩的问题；新增「暂不发送」，可关闭弹窗并保留输入内容。
- 修复对话压缩摘要被重复显示成用户消息气泡的问题，摘要现在只保留紧凑的压缩节点。
- 修复 `/自定义风格` 在活动任务中排队后失效、发送内容拆成两条消息、输入框残留命令文本等问题；重新打开 Kimix 时也不会重复弹出同一风格的导入提示或覆盖当前选择。
- 加强自定义风格生成要求：文字和背景、相邻容器层级、悬停与选中状态必须保持清晰可辨，减少低对比度和「所有区域看起来一样」的风格结果。
- 收敛自定义风格下同行控件的轮廓：Composer 的 Swarm、Plan、Tower 与思考强度，顶部启动/打开组合按钮与普通工具按钮，MCP 表单字段及 Agent 弹窗主次操作保持一致几何；菜单展开前后不再突然改变圆角。
- 修复文件变更卡片底部「再显示 N 个文件」在部分风格及悬停状态下出现黑线的问题。
- 模型与供应商列表改为按配置添加顺序从旧到新展示，不再把默认模型强行置顶后重新排序。

## 已知边界

- 自动导入要求 Agent 能写入 Kimix 风格收件箱；无法访问该目录时，可让 Agent 返回 JSON 文件并通过设置页「导入 JSON」手动导入。
- 自定义风格只接受 UI Style v1 JSON，负责颜色种子、材质、圆角和交互状态，不执行任意 CSS、脚本、网络资源或布局改写。
